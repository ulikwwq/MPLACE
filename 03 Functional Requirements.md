FR-001 — Authentication Module
1. Назначение модуля

Authentication Module отвечает за:

регистрацию пользователей;
подтверждение номера телефона;
вход в систему;
управление сессиями;
выдачу токенов доступа;
восстановление доступа;
безопасность пользовательских аккаунтов.

Модуль является базовым для всех остальных модулей системы.

2. Основные принципы
AUTH-001

Регистрация пользователя выполняется только через номер телефона.

Поддерживаемый канал:

SMS подтверждение.

Email регистрация отсутствует.

AUTH-002

Аутентификация реализуется через:

Access Token;
Refresh Token.

Используется JWT.

AUTH-003

Пароли пользователей не хранятся в открытом виде.

Все секретные данные должны храниться только в зашифрованном виде.

AUTH-004

Все действия авторизации записываются в Security Log.

3. User Registration
AUTH-005 — Запрос регистрации

Пользователь вводит:

{
  "phone": "+996XXXXXXXXX"
}

Система:

Проверяет формат номера.
Проверяет существование пользователя.
Создает временную регистрацию.
Отправляет SMS-код.
Сохраняет информацию о попытке.
AUTH-006 — Формат телефона

Система поддерживает номера:

Кыргызстан

+996XXXXXXXXX
AUTH-007 — Отправка SMS кода

После запроса регистрации система отправляет одноразовый код.

Параметры:

длина кода: 6 символов;
срок действия: ограниченный;
количество попыток ограничено.
AUTH-008 — Проверка SMS кода

Пользователь отправляет:

{
 "phone":"+996XXXXXXXXX",
 "code":"123456"
}

Система:

проверяет код;
подтверждает номер;
создает пользователя;
создает сессию;
выдает токены.

AUTH-012

Module: 1C Integration

ID Prefix: ERP
Назначение

Обеспечивает двустороннюю синхронизацию между MPlace и 1С.

Основной принцип

Все взаимодействие происходит только через REST API и слой адаптеров.

Business Service

↓

1C Adapter

↓

REST API

↓

1С

товары;
категории;
бренды;

остатки;

Из MPlace → 1С
новые заказы;

отмены заказов.

Все обмены выполняются через RabbitMQ.

администратор получает уведомление.
